# Wave 18b lane 3: release-note material for the integrator

Lane 3 does not touch VERSION, CHANGELOG headers or `BEHAVIOR_CHANGES` `since:` values. The integrator folds these into the wave's CHANGELOG entry and `BEHAVIOR_CHANGES` rows (stamped with the wave's release).

## CHANGELOG bullets (Itemized changes)

- **Dream patterns: timeline appends are quote-verified and counted (#6302).** A patterns child mostly updates existing pattern pages with `add_timeline_entry`. The phase now selects the entries it newly published by write receipt (a committed `persistence_requests` row with outcome `ok`, deduplicated by request id and entry, so replays and skipped re-appends don't count again). It quote-verifies only those entries against this run's reflections. A failing entry moves to `unverified_claims` and its timeline row is removed; earlier verified content on the page is left alone. Those pages get provenance stamps and count in `patterns_written`. New result fields: `details.timeline_appends` and `quote_verify.timeline_appends`. `appended_unverified` is kept as a deprecated alias (TOOL_REFERENCE note) and removed two releases later. Files: `src/core/cycle/patterns.ts`, `test/cycle-patterns-timeline-appends.serial.test.ts`, `docs/guides/dream-patterns.md#timeline-appends`.
- **Dream patterns: in-cycle cadence and a child read budget (#6297).** An in-cycle patterns run (autopilot, bare `gbrain dream`) now waits `dream.patterns.min_interval_hours` (default 6, `0` off) after the partition's last completed run. It skips with `patterns_min_interval` and reports `next_eligible_at`. A direct `gbrain dream --phase patterns` and `--once` aren't held to it. The stamp is per source incarnation, and the external-reflections partition has its own. The patterns child's `get_page` results are now budgeted at `dream.patterns.child_read_budget_kb` (default 200 KB, `0` off). Bytes are counted from the job's own tool-execution ledger, and past the budget a read returns a summary (`truncated: true`, `code: read_budget_exhausted`). Files: `src/core/cycle/patterns-plan.ts`, `src/core/cycle/phase-config-values.ts`, `src/core/minions/tools/read-budget.ts`, `src/core/minions/tools/brain-allowlist.ts`, `src/core/minions/handlers/subagent.ts`, `src/core/cycle.ts`, `src/commands/dream.ts`, `docs/guides/dream-patterns.md#cadence`, `#child-read-budget`.
- **`gbrain trust backfill --repair-unknown-markers` (#6550).** This is a local-CLI repair for pages that an agent edit before v0.60.249.0 stamped with `trust_tier: unknown`, and that a later backfill classified higher. By default it previews: the slug, current marker, stored tier, proposed marker and tier, and the evidence (the first saved version that shows the marker, compared with when the fixed release first ran, and whether the first import had the marker). Pages are split into "consistent with #6550" and "ambiguous", and the preview ends with `Apply with: <exact command>` naming only the consistent pages. Apply needs `--slug` (repeatable) plus `--expect <preview hash>`, and rewrites only the named pages at their previewed revisions: the marker becomes the stored tier (none at owner tiers) and the tier stays. `gbrain trust review` adds a `repair` command to `lower_page` items that an unknown marker caused. Files: `src/core/trust/marker-repair.ts`, `src/core/trust/page-handlers.ts` (`trust_owner_page` mode `repair_marker`, refused for remote requests), `src/core/trust/review.ts`, `src/cli/commands/trust.ts`, `docs/guides/memory-trust.md#repair-unknown-markers`.
- **Doctor `embedding_identity_unqualified` (#6113).** A new check warns when the brain's `embedding_model` config row has no provider prefix, which is a row from an older install that stops managed fact extraction. It prints a copy-paste `gbrain migrate embeddings --to <provider:model> --dry-run`, filled from the configured model (an `inputs` entry only when none is configured), and calls out a model switch when the configured model differs. The free relabel stays parked (TODOS P2). Files: `src/commands/doctor/checks/embedding-identity.ts`, `docs/guides/troubleshooting.md#embedding-identity-unqualified`.
- **Docs: CJK fact subjects (#6620).** The facts guide now says that CJK fact subjects need a literal slug or a delimiter, and that inferring unspaced natural names isn't supported. The brief named `docs/guides/facts.md`, which doesn't exist, so the section is in `docs/guides/facts-relink.md`. A probe in `test/facts-subject-infer.test.ts` pins the documented behavior.
